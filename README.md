# 抖音续火花cc

抖音「自动续火花」LSPosed 模块。给抖音判定今天还没互动的会话，自动发一条你自己写的私信，每会话每天最多一条。

## 它能做什么

- **自动续火花**：五档分类（全部 / 已燃 / 待燃 / 待续 / 无火花），该发的自动发，也可以手动勾选发
- **互动表情**：发抖音的火焰表情（`msgType=5`），不是文字；目录从抖音配置里读，当前 21 个
- **定时唤醒**：每天到点用 root 拉起抖音发完再关掉，不亮屏、不解锁
- **模板**：内置 2 个，自定义支持继承（跟随父模板）和克隆（复制后独立）
- **零联网**：不申请 `INTERNET`，头像和表情图都由抖音进程取好后推过来

## 安装

1. 装 APK
2. LSPosed 里启用，勾作用域「抖音」（装完通常已自动勾好）
3. **强制停止抖音再打开**
4. 打开模块 App 一次，看「设置 → 宿主心跳」有没有内容

覆盖安装不丢配置；**换签名或卸载会丢**，先「设置 → 导出配置」备份。

## 界面

抽屉五个入口：**续火花 / 模板 / 变量 / 设置 / 使用文档**，右上角 ⚙ 直达设置。

**续火花**：顶部深色卡显示记录时间、已续 / 已燃 两个比值、三个胶囊（还能发几个 / 下一轮几点 / 几个模板）。下面五档分段，每行是头像 + 名字 + 状态标签 + 火花天数 + 右侧开关。开关只是「选中」，勾完底部才出现红色「发送 N 个」。

**模板**：内置两张 + 我的模板，每张卡有编辑 / 按条预览 / 克隆 / 重命名 / 删除。克隆可以按四档筛、可全选本组。

**变量**：列出脚本里能直接用的真实路径（`ctx.io.days` 这种）和当前样例值；模板变量与会话变量分开管，会话层同名覆盖模板层。

**设置**：发送（总开关 / 只在设定时间检查）、定时唤醒（选时间 / 关闭）、诊断（运行日志 / 宿主心跳）、数据（导出 / 导入 / 表情图缓存）、关于。

**编辑弹层**：底部四个按钮——模板 / 表情 / 变量 / 预览。表情点开是 21 个表情的网格，内容空就插整句、非空就插片段。保存时自动清掉零宽字符和中文引号。

## 什么时候会发

抖音冷启动（等 5 秒起探测）、回到前台、跨天补跑、定时唤醒、手动点发送。

- 自动轮只发「待续」，其他档可以手动勾选发
- 每会话每天最多一条，跨天重置
- 抖音没在运行就发不出去（模块注入在抖音进程里）
- 一个会话最多 3 段

**总开关只管自动轮，不拦手动点**。

## 定时唤醒（需要 root）

模块代码跑在抖音进程里，抖音不启动就没人干活。所以到点用 `AlarmManager` + root `monkey` 把抖音拉起来：

```
到点 → AlarmManager 叫醒模块 → su -c monkey 拉起抖音（不亮屏）
     → 扫描 → 发送 → 写标记 → 模块检测到已发 → am force-stop 关掉抖音
```

`monkey` 只接受 root 或 shell 身份，普通 App 执行会被 `Killed`，所以**没有 root 就没有定时唤醒**，不做降级。

申请 4 个权限：`SCHEDULE_EXACT_ALARM` `USE_EXACT_ALARM` `RECEIVE_BOOT_COMPLETED` `WAKE_LOCK`。没有 `INTERNET`、没有悬浮窗、没有存储权限。

注意：手动「一键清理」会把闹钟一起清掉，需要手动开一次本模块 App 恢复。

## 脚本 API

脚本是 JavaScript，跑在 Rhino 里，能力全挂在 `ctx` 上。

```js
// 最小写法：发一条文字
ctx.result.push("火花 " + ctx.io.days + " 天啦");

// 分条发：commit 一次切一条，最多 3 条
ctx.result.push("早，今天也续上");
ctx.commit();
ctx.result.push("火花别断");

// 发表情：自成一条，不跟文字合并
ctx.result.push({ type: "emoji", name: "续火花" });
```

| 方法 | 作用 |
|---|---|
| `ctx.result.push(x)` | 加一行；空列表 = 这条不发 |
| `ctx.commit()` | 把当前内容收成一条，之后接着攒 |
| `ctx.submit()` / `ctx.exit()` | 收尾立刻结束 / 放弃这一轮 |
| `ctx.emoji.list()` / `get(name)` / `emoji(name)` | 表情目录（21 个） |

变量分两处：`ctx.builtin`（`date` `time` `weekday` `timestamp` `pick` `random` `shuffle` `countdown` `formatDate`）和 `ctx.io`（`nickname` `remark` `name` `days` `state` `stateText` `peerUid` `id`）。自定义变量在 `ctx.template.vars["名字"]`，**没有裸变量名**，写 `nickname` 会报 `ReferenceError`。

报错会显示成 `失败：XXX（脚本第 3 行出错：missing variable name）`，行号是你的脚本里的行号。

## 常见问题

**「待续」是 0？** 今天该发的都发完了，明天再来。

**发了没反应？** 确认抖音在运行；看「设置 → 运行日志」；改完 APK 必须重启抖音。

**已燃和待燃的区别？** 已燃 = 抖音说今天已互动；待燃 = 我们发了但对方没回。

**半夜突然发出去了？** 跨天补跑不受「只在设定时间检查」管辖，不想半夜发就把它打开。

**闹钟响了抖音没起来？** ① KernelSU/Magisk 里给本模块授权；② 是否做过一键清理；③ 是否装了两个同包名版本。

**给没火花的人发？** 在「无火花」档点进去写脚本，勾选后手动发。别一次发太多。

**配置会不会丢？** 覆盖安装不会，换签名或卸载会。先导出备份。
